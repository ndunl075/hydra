# Native staged installer verification

`native/desktop-update-staged-verifier.cpp` connects the operation-ID path lease to the Authenticode verifier. It opens the fixed staged path, holds every ancestor and the installer against rename or write, and passes that same file handle to the byte-length, SHA-256, and signer checks. A failed decision closes the lease; an accepted decision returns the still-open lease to its caller. The future helper must retain it through installer process creation.

The profile root, digest, length, signer, and expected version accepted by these primitives are test inputs, **not** production authority. An installed helper still needs to derive the Hydra profile and installed signer policy itself, authenticate the durable operation and consent, and enforce the release owner's timestamp/revocation policy. This feature has no process launch or update activation.

`native/desktop-update-pe-identity.cpp` adds a handle-based PE version-resource check. `verify_staged_hydra_installer` requires the resource product name `Hydra`, its stable `ProductVersion` string, and the fixed numeric product version to match an expected release version before Authenticode verification. It retains the same locked staged-file lease and closes it on either identity or signature failure. The expected version is a test input here; the future installed helper must obtain it from authenticated metadata. The older `verify_staged_installer` remains a signature-only fixture primitive. A disposable-built unsigned Hydra installer passes the identity-only test, while a signed browser fails the integrated Hydra identity check. Neither proves a signed Hydra release.

`scripts/desktop-native-staged-verifier-test.ps1` compiles a test-only caller and stages an existing signed browser executable under the fixed updater path. It checks accepted bytes and signer plus refusal for wrong hash, length, signer, operation ID, hard link, reparse-point ancestor, and tampered signed bytes. The Windows desktop workflow runs it before packaging. This fixture does not substitute for controlled Hydra-signed release acceptance.
