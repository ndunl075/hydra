An agent's change, reviewed before it lands.One diff. One commit.

Hydra makes a worktree for every task, checked out at committed HEAD on its own branch. Your agent works there whether it is Claude Code or Codex. You read the diff, stage what you want, and commit the tree you reviewed. Then the worktree can go.

  • → A worktree per task, at committed HEAD
  • → The agent runs there, with scoped approvals
  • → You commit the tree you reviewed

Own branch, own worktree

Each task starts at committed HEAD in a unique branch and sibling worktree. Dirty main-checkout edits stay where they are.

Reserved resources

Ports and database or service names are reserved per task before first launch, and reservations survive restart.

Setup must pass

Saved setup commands run in the checkout first. Provider work does not launch until they succeed.

Prepare commit review

Freeze a fixed tree against the task base and inspect it. Stale changes, active writers, and unsaved task buffers refuse.

Commit reviewed tree

Creates the exact reviewed commit, or records one already made. Your native Git hooks still apply.

Local receipt, not a merge

Integrating the target branch is a separate, explicit step. Hydra never merges on your behalf.

Scheduling

Run several at once, inside a limit you set. Two active managed sessions per window by default. The rest wait in a persistent queue with explicit dependencies.

Agent map

Every worktree on one canvas

Moving arrows are local sessions

They stop for approvals. External sessions stay static because their progress is unavailable.

IllustrativeThe map follows the editor theme and the reduced-motion preference and makes no model requests. Agent-to-agent dependencies and message flow are not implemented yet.

Persistent queue

Excess launches wait with explicit dependencies and are reconciled after restart.

Soft budgets

Task and project budgets can warn or hold new work using reported usage. Holds require an explicit retry.

Shared profile capacity

A reservation limit shared across participating windows in one local profile. Uncertain writers keep their slots until explicit recovery.

Handoff

Hand a task to the official extension when it makes sense. A separate window, only that checkout, the task prompt, and nothing submitted until you press the button.
