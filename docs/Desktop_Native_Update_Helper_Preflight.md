# Native update-helper identity preflight

The Windows x64 build now includes `tools/HydraUpdateVerify.exe` in the standalone editor and per-user installer. Its bootstrap policy is compiled with updates disabled. The executable accepts exactly one canonical lowercase version-4 operation UUID; it accepts no path, hash, signer, version, pipe, fixture, or installer arguments. Every invocation currently refuses. It does not connect to Electron main, open a staged installer, advance the update journal, launch a child process, restart Hydra, or contact a server.

Before the disabled-policy refusal, the helper independently obtains the current token SID and session, known-folder profile/local/roaming/UserProgramFiles paths, its own executable path, the fixed HKCU Hydra user-install registration, and `Hydra.exe`'s PE product version. It refuses elevated, system/session-zero, redirected, archive, portable, alternate-helper, or mismatched installations. It opens and retains handles on the installation, profile, `Hydra.exe`, helper, and ancestors while checking that they are not reparses; executable files must have one hard link. No observation supplied by a caller can override this policy.

The native test binary is compiled separately and never packaged. It exercises default-path, SID/session, version, operation-ID, actual hard-link, and junction refusals. The disposable installer test verifies the disabled helper is installed, remains refusing, and is removed with Hydra. PE version checks require it to match the Hydra release.

This preflight is **not** signed installer verification or an authenticated main/helper handoff. A same-user ACL or mutable installed `product.json` cannot authenticate Electron main. Later features must add a compiled trust root and owner-signed installed-code inventory; a private one-operation handoff with process binding; native reauthentication of the signed journal candidate and artifact; explicit timestamp/revocation policy; shutdown consent and veto; and an installer launch held under the verified lease. The shipping update channel remains disabled.
