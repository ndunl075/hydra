# Cite sources

Every factual claim needs a citation that lets someone else check it in under a minute.

## What a citation needs

For each claim, give:

1. **The link** — the actual URL you read, not a search results page or a homepage.
2. **The title** — the page or article's own title, not a paraphrase.
3. **The date** — when the page was published or last updated. If the page has no visible date, say so rather than guessing.
4. **The quote** — a short, exact excerpt from the source that the claim actually rests on. Quote the sentence that supports the claim, not a nearby paragraph that merely sounds relevant.

A simple inline format works well:

> The API rate limit is 500 requests per minute. ([Rate limits — Acme Docs](https://example.com/docs/limits), updated 2026-03-14: "the default limit is 500 requests per minute per API key")

## Choosing sources

- Prefer the primary source (the vendor's own docs, the original paper, the official announcement) over a blog post summarizing it.
- Prefer a source with a visible date over one without, especially for anything that changes over time (pricing, limits, version numbers).
- If two sources disagree, cite both and say so — don't silently pick one.

## Marking a claim [unverified]

When you cannot find a source that actually supports a claim — the claim has none, the source you found doesn't say what's claimed, or you ran out of time to check it — mark the sentence:

> Claim text here. [unverified: no source found that states this figure]

Keep the reason short but specific enough that the next person knows exactly what's missing: "no source found," "source doesn't give this exact number," "source is over five years old," and so on. Never leave a claim both uncited and unmarked.
