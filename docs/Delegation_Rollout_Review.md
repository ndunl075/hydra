# Delegation rollout review

Feature 21 is a local, read-only human review gate. It creates a versioned, SHA-256-integrity-checked packet containing the Feature 14 evaluation report, Feature 17 passive readiness facts, Feature 19 operator-bound native-acceptance records, Feature 18 release provenance, and the Feature 20 delegated-run export. The packet also records an explicit human decision with operator, UTC timestamp, and rationale.

Creating or parsing a packet never opens a provider, reads an artifact file, starts a process, sends telemetry, publishes a release, or changes `hydra.delegationMode` or any provider setting. In particular, Feature 17's `ready: false` is a deliberate passive-preflight value and is preserved as a fact; it is not treated as an implicit setting change.

Approval is assessed only against caller-supplied current facts. The trusted host remains responsible for validating the Feature 14 corpus and ledger before supplying its report and references; this packet binds those supplied facts but does not claim to attest to them. It fails closed when the decision is rejection, the report lacks complete eligible samples, any packet or source hash changed, a native gate is pending, release manifest/signing/manual provenance is missing, evaluation references differ from the Feature 20 export, or evaluation references are unavailable. Feature 20 currently exports unavailable evaluation references until its later host integration, so such packets remain reviewable but cannot be approved.

Packets use canonical JSON hashing, copy and freeze their inputs, and persist through the bounded atomic `DelegationRolloutReviewStore`; a restarted store returns the exact sealed packet and rejects a conflicting writer. The trusted host must verify the actual manifest and artifacts before it supplies hashes: the packet binds supplied facts but does not establish their origin. Native artifact source commits must match the release source commit, and a decision cannot predate its native evidence. A corrupted packet, malformed evidence reference, duplicate gate, mismatched stored hash, or changed current fact is rejected without attempting recovery or replay of a provider/process action.
